# Estructura de Campañas Meta Ads

**Curso:** Meta Ads a Fondo (La Tribu Divisual / Skool) — Zona Técnica (NV2)  
**Fuente:** Video Loom (~15 min)  
**Cobertura:** Completa

## De Qué Trata

Esta lección fundamental explica la arquitectura jerárquica de las campañas publicitarias en Meta Ads. Comprende los tres niveles estructurales que conforman cualquier campaña: campañas, conjuntos de anuncios (ad sets) y anuncios individuales. La comprensión de esta estructura es crítica antes de crear cualquier campaña, ya que cada nivel tiene funciones específicas y configuraciones propias.

## Contenido Detallado

### Importancia de Entender la Estructura

Antes de crear o lanzar cualquier campaña publicitaria en Meta, es indispensable comprender claramente cómo se organizan jerárquicamente los diferentes componentes. Esta comprensión permite tomar decisiones informadas en cada nivel de la campaña y optimizarla correctamente.

### Los Tres Niveles de la Estructura

Meta Ads utiliza una estructura de tres niveles que funciona como un árbol jerárquico:

**Campañas (Campaign):** Es el nivel superior. Una campaña agrupa los objetivos generales de tu publicidad. Es el contenedor que define qué deseas lograr (generar leads, aumentar tráfico, generar ventas, etc.).

**Conjuntos de Anuncios (Ad Sets):** Es el nivel intermedio. Cada conjunto de anuncios dentro de una campaña especifica el público objetivo (audiencia), el presupuesto asignado, el período de duración y las optimizaciones específicas para ese segmento de audiencia.

**Anuncios (Ads):** Es el nivel más granular. Aquí residen los elementos creativos: el contenido visual, el texto, las llamadas a la acción (CTAs) y los formatos específicos del anuncio. Un conjunto de anuncios puede contener múltiples anuncios que Meta testea simultáneamente.

### Acceso al Administrador de Anuncios

Para acceder a la interfaz donde se configura toda la estructura de campañas, debes:

1. Ir a tu cuenta de Meta (Facebook Business)
2. Buscar la opción "Administrador de Anuncios" en el menú principal
3. Acceder a "Todas las herramientas" si es necesario
4. Dentro del Administrador, verás tus campañas creadas organizadas según esta jerarquía

### Interfaz del Ads Manager

El Administrador de Anuncios presenta un panel donde se visualizan todas tus campañas activas y previas. Este panel muestra información agregada de cada campaña y permite acceder a los detalles de cada nivel. Es importante familiarizarse con esta interfaz desde el principio.

## Puntos Accionables

- Memoriza la jerarquía: Campaña > Conjunto de Anuncios > Anuncios
- Entiende que cada nivel tiene configuraciones y objetivos independientes
- Accede al Administrador de Anuncios y explora cómo se estructuran las campañas existentes
- Antes de crear una nueva campaña, define primero tu objetivo a nivel de campaña
- En el siguiente nivel (ad sets), define tu audiencia objetivo y presupuesto
- Finalmente, crea los anuncios creativos que resonarán con esa audiencia específica
- Asegúrate de tener claro este modelo antes de pasar a las lecciones de creación de campañas
