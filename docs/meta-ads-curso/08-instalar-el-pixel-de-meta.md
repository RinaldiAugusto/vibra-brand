# Clase 08 — Instalar el Píxel de Meta

**Curso:** Meta Ads a Fondo (La Tribu Divisual / Skool) — Zona Técnica (NV2)
**Fuente:** video Loom (~duración no determinada)
**Cobertura:** ⚠️ PARCIAL — Loom solo entregó transcripción gratuita de los primeros minutos; el resto del video no está reflejado en estas notas.

## De qué trata

Continuación de la clase anterior: una vez que tienes el Píxel de Meta creado en el Business Manager, es necesario vincularlo e instalarlo en tu sitio web. Esta clase muestra el procedimiento específico usando WordPress como plataforma de ejemplo, aprovechando un plugin existente que ya conoces (Pixelturesight).

## Pasos para instalar el Píxel en WordPress

### 1. Prerequisitos

Antes de comenzar la instalación, asegúrate de tener:
- El Píxel de Meta ya creado en el Business Manager (completado en la clase anterior).
- Tu sitio web WordPress accesible y con permisos de administración.
- El plugin **Pixelturesight** instalado en WordPress (se menciona que es un plugin que ya fue usado anteriormente en el curso para verificar el dominio).

### 2. Ubicación del plugin en WordPress

Dentro de tu panel de administración de WordPress, accedes a la sección de plugins o herramientas donde se encuentra **Pixelturesight**. Este plugin actúa como intermediario entre tu sitio WordPress y el Píxel de Meta de Meta Business Manager.

### 3. Vinculación y verificación

Una vez dentro del plugin, procedés a:
- Conectar/vincular el Píxel que creaste previamente.
- Verificar que la conexión sea correcta y que los datos comencen a fluir desde tu sitio web hacia Meta.

## Puntos accionables

- Verifica que tu Píxel de Meta está completamente creado y disponible en el Business Manager antes de intentar instalarlo.
- Accede a tu panel de WordPress y busca el plugin Pixelturesight.
- Utiliza el plugin para vincular tu Píxel de Meta a tu sitio WordPress.
- Una vez instalado, haz seguimiento para verificar que la instalación fue exitosa y que Meta está recibiendo eventos desde tu sitio.
