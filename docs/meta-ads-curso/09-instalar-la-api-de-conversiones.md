## De qué trata

Después de crear e instalar el Píxel de Meta en tu sitio web, el siguiente paso es configurar la **API de Conversiones**. Esta es la herramienta que permite a Meta recibir y procesar información detallada de eventos y conversiones que ocurren en tu sitio. La clase guía a través del Administrador de Eventos, donde se vinculan y configuran los eventos que Meta debe rastrear.

## Pasos para instalar la API de Conversiones

### 1. Acceso al Administrador de Eventos

Para comenzar, accedes a tu **Business Manager** y navegas hacia el **Conjunto de Datos** (el Píxel que ya creaste). En la interfaz del Conjunto de Datos, encontrarás un menú de opciones (típicamente representado por tres puntos). Seleccionas la opción que dice **Abrir en el Administrador de Eventos** (o similar, según la versión actual de Meta).

### 2. Ubicación alternativa del Administrador de Eventos

Si no encuentras la opción anterior, el **Administrador de Eventos** también es accesible directamente desde el menú principal del Business Manager. Busca en la sección de Herramientas o en el menú hamburguesa. Una vez que lo hayas usado recientemente, Meta también lo mostrará en la sección "Utilizado recientemente" para acceso rápido.

### 3. Visualización de Conjuntos de Datos/Píxeles

Una vez dentro del Administrador de Eventos, verás una lista de todos tus **Píxeles** o **Conjuntos de Datos** disponibles. Este es el punto central donde configurarás qué eventos específicos Meta debe rastrear desde tu sitio web.

### 4. Configuración de eventos

Desde esta pantalla, procedes a:
- Seleccionar el Píxel/Conjunto de Datos que deseas configurar.
- Definir y vincular los eventos específicos que Meta debe rastrear (como "compra", "registro", "vista de página", etc.).
- Verificar que cada evento esté correctamente mapeado a las acciones que ocurren en tu sitio web.

## Concepto: Píxel vs. API de Conversiones

- El **Píxel de Meta** es el contenedor o identificador central que Meta usa para asociar eventos a tu negocio.
- La **API de Conversiones** es el mecanismo técnico mediante el cual los eventos se envían desde tu sitio web a Meta para ser procesados y utilizados en la optimización de campañas.

Ambas herramientas trabajan en conjunto: el Píxel identifica *quién* está generando los eventos, y la API es el *canal* por el cual esos eventos llegan a Meta.

## Puntos accionables

- Asegúrate de tener un Píxel creado e instalado antes de configurar la API de Conversiones.
- Accede al Administrador de Eventos desde tu Business Manager o directamente desde el menú del Conjunto de Datos.
- Configura los eventos específicos que deseas rastrear (compras, leads, registros, etc.).
- Verifica que la vinculación entre tu sitio web y los eventos esté correctamente establecida.
- Prueba que los eventos se están registrando correctamente en el Administrador de Eventos.
