## De qué trata

Explicación sobre la necesidad de vincular y verificar un dominio (sitio web) con Business Manager, cómo funciona el seguimiento de Meta a nivel de página web, y por qué esta vinculación es crítica para optimizar campañas publicitarias.

## Contenido detallado

### Progreso en el módulo

Se reafirma que si el estudiante ha llegado hasta este punto y entiende los pasos anteriores, va por buen camino. Estos son pasos fundamentales para configurar completamente una Business Manager tanto para:
- Lanzar anuncios propios
- Lanzar anuncios de clientes (tema que se profundizará posteriormente)

### ¿Qué es un dominio?

**Definición fundamental**

Un dominio es la dirección web de un sitio — el formato `www.paginaweb.com` que todos conocen. No es literalmente la página web entera, sino el identificador único que apunta a ella.

**Requisito no negociable**

El instructor hace énfasis: si no posees una página web, debes crear una. Es un requisito fundamental para operaciones profesionales de marketing digital, especialmente si planeas usar Meta Ads. No existe campana publicitaria seria sin un sitio web de destino.

**Analogía con marca**

Así como es necesario tener marca y presencia de marca, también es necesario tener un dominio/sitio web. Esto es parte del ecosistema básico para hacer publicidad digital profesional.

### Verificación de dominio con Business Manager

**Qué significa verificar un dominio**

Verificar un dominio significa vincular oficialmente tu sitio web con tu cuenta de Business Manager. El proceso se realiza a través del dominio (no hay que verificar cada página individual, solo el dominio raíz).

**Por qué es importante**

Cuando tu Business Manager está vinculado a tu página web, Meta obtiene acceso a información sobre el comportamiento de los usuarios dentro de tu sitio:
- Meta puede rastrear todas las acciones que realiza cada usuario en la página
- Puede registrar comportamientos, clics, compras, formularios completados, etc.
- Esta información se integra con la plataforma de Meta

### El poder del seguimiento integrado

**Optimización basada en datos de comportamiento**

La razón principal para vincular dominio + Business Manager es que Meta puede optimizar tus anuncios mucho más efectivamente cuando tiene acceso al comportamiento real del usuario después del clic.

Con el dominio vinculado, Meta "ve":
- Si el usuario que hizo clic en tu anuncio terminó comprando algo
- Si completó un formulario
- Cuánto tiempo pasó en la página
- Qué acciones tomó
- Dónde abandonó

**Feedback loop de optimización**

Este flujo de información permite que Meta mejore continuamente:
1. Lanza anuncios a una audiencia
2. El usuario hace clic
3. Meta rastrea qué sucede después
4. El sistema aprende cuáles usuarios convierten
5. Los algoritmos mejoran el targeting futuro

Sin esta información, Meta solo sabe "que hizo clic" pero no "si convirtió", lo que debilita significativamente la optimización.

### Vinculación de dominio en Business Manager

**Proceso**

El dominio se vincula a través de:
- Business Manager
- O Business Suite (aunque Business Manager es el recomendado para control total)

Cuando se vincula un dominio, Meta obtiene acceso a todo el sitio web bajo ese dominio.

**Múltiples dominios**

Es posible asignar múltiples dominios a una sola Business Manager, útil para:
- Agencias que manejan varios clientes
- Empresas con múltiples marcas o sitios
- Portales con distintos subdominios

## Puntos accionables

- Si no tienes página web, crearla es prioritario (no se puede hacer publicidad profesional sin ella)
- Verificar y vincular tu dominio en Business Manager lo antes posible
- Entender que la vinculación de dominio permite que Meta rastree completamente el comportamiento post-clic
- Este seguimiento es la base para la optimización efectiva de campañas
- Si trabajas con múltiples clientes o marcas, configurar múltiples dominios en la Business Manager para cada uno
- Mantener la vinculación de dominio activa en todo momento para garantizar que Meta sigue recibiendo datos de optimización
