# Base de conocimiento — Curso "Meta Ads a Fondo"

## Qué es esto

Notas de las 23 clases del módulo **"Curso Completo Meta Ads"** dentro de "Zona Técnica (NV2)", un curso pago en Skool (comunidad **La Tribu Divisual**) que el equipo de **Vibra** compró para tener criterio propio de Meta Ads a la hora de vender y ejecutar campañas para clientes (incluyendo la estrategia de adquisición de **TurnosBot**).

El objetivo de esta carpeta es que cualquier persona del equipo — o cualquier instancia de Claude que trabaje con el equipo — pueda consultar rápido "qué dice el curso sobre X" sin tener que volver a mirar los videos.

## Cómo se armó (importante para entender las limitaciones)

Los videos del curso están alojados en **Loom** (con subtítulos/transcripción automática) y uno en **YouTube**. Estas notas se generaron:

1. Extrayendo la transcripción automática de cada video.
2. **Reescribiéndola como apuntes propios, en prosa organizada — nunca como copia literal del video.** Esto es deliberado: un transcript palabra por palabra de un curso pago es contenido con derechos de autor de terceros (La Tribu Divisual / el instructor), y no correspondía reproducirlo entero. Lo que hay en cada archivo es un resumen fiel y detallado del contenido — conceptos, pasos técnicos, cifras, ejemplos — parafraseado.
3. Para la clase 02, además se incorporó el contenido del PDF "Documentación" adjunto en Skool (una presentación de conceptos).

**Si necesitás una cita textual exacta de algo que dijo el instructor** (para un guión, un post, etc.), estas notas no alcanzan — hay que volver a ver el video puntual en Skool.

## Limitación conocida: cobertura parcial en algunas clases

Loom solo entrega la transcripción **gratis** hasta cierto punto; para seguir leyendo pide crear una cuenta de Loom, algo que deliberadamente no se hizo (no correspondía crear cuentas de terceros para esto). Por eso, en las clases más largas, las notas solo cubren los primeros minutos del video:

| Clase | Estado |
|---|---|
| 02 — Conceptos básicos y Cuentas | ⚠️ Parcial (compensado con el PDF adjunto) |
| 06 — Pixel de Meta y API de Conversiones | ⚠️ Parcial |
| 07 — Creación del Pixel de Meta | ⚠️ Parcial |
| 08 — Instalar el Pixel de Meta | ⚠️ Parcial |
| 09 — Instalar la API de Conversiones | ⚠️ Parcial |
| 22 — Workshop Meta Ads a Fondo (1h19min) | ⚠️ Parcial — es la que menos cobertura tiene, el workshop es muy largo |

El resto de las clases son videos cortos (2 a ~20 min) donde la transcripción gratuita alcanzó a cubrir el contenido completo. Cada archivo dice explícitamente en el encabezado ("Cobertura") si es completo o parcial — **conviene mirar ese campo antes de asumir que una nota lo cubre todo**, sobre todo en 06-09 y 22.

## Para otro Claude que llegue a esta carpeta

- Tratá cada archivo como **notas de referencia**, no como la fuente primaria — son un resumen fiel pero parafraseado del video, hecho por otra instancia de Claude.
- Si el usuario pide algo muy específico (un número exacto, una frase textual del instructor) y el archivo no lo tiene con precisión, decilo — no inventes el dato.
- Las clases marcadas ⚠️ Parcial tienen huecos reales de contenido. Si el usuario pregunta algo de esas clases que no está en la nota, lo más honesto es decir "esto no llegó a cubrirse en la transcripción disponible" en vez de completar con conjeturas.
- El origen es un curso de venta de Meta Ads orientado a agencias — el enfoque de todas las clases es práctico/operativo (cómo configurar, qué botón tocar, qué campaña elegir), no teoría de marketing abstracta.
